# SCI — Safe Claude Integration

CLI tool for secure Claude Code isolation on macOS.

## Install

curl -fsSL https://raw.githubusercontent.com/MikolajMys/sci/main/install.sh | bash


## Commands
- `sci setup` — full interactive setup on a new machine
- `sci repair` — diagnose and fix after macOS update
- `sci verify` — run all verification checks
- `sci status` — show current state overview
